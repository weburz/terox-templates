## Adding a new page

Drop a numbered markdown file into a section directory under `content/`. The
filename prefix controls navigation order; the `.navigation.yml` at the
section root controls the section title and icon.

```
content/
├── 1.getting-started/
│   ├── .navigation.yml
│   ├── 1.introduction.md
│   └── 2.installation.md
└── 2.guide/
    ├── .navigation.yml
    └── 1.overview.md
```

## Frontmatter

Each page declares its title and description via frontmatter. The schema
lives in `content.config.ts`:

```yaml
---
title: Page title
description: One-sentence summary used for SEO and TOC.
---
```

## Nuxt UI components in Markdown

Nuxt Content supports Nuxt UI components inline via the `::` and `:`
shorthand syntax:

```markdown
::callout{icon="i-lucide-lightbulb"}
A boxed callout with an icon.
::

:u-button{to="/getting-started/installation" label="Install" color="primary"}
```

See the [Nuxt UI Pro docs](https://ui4.nuxt.com/components) for the full
component list.
